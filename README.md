# Boxelle-website
Official website project for BOXELLE, a premium bakery and food packaging brand in India. Built with WordPress and WooCommerce.

## Homepage Design Preview

Before building the final WordPress site, the homepage layout and visual
direction are being prototyped as static HTML/CSS in [`design-preview/`](./design-preview).
This lets the look and feel be reviewed and adjusted quickly, before it's
translated into the actual WordPress theme/page-builder implementation.

To view it locally, just open `design-preview/index.html` in a browser
(no build step required).

**Sections included:** header/navigation, hero, brand story, signature
collections, "why choose us", signature showcase, testimonials, Instagram
gallery, newsletter CTA, and footer — fully responsive for desktop, tablet,
and mobile.

**Still needed to finalize the design:**
- BOXELLE logo file (currently a text wordmark)
- Real product/brand photography (hero photo, collection images, gallery)
- Final homepage copy (the current text is placeholder content)
- The original reference screenshot, if further alignment to it is wanted

See `design-preview/assets/img/README.txt` for exactly which placeholders
need real images.
